# 失败归因分析框架

用户复盘实验失败时，按以下框架做归因分析：

1. **现象归类**：先读实验记录的 notes / self_summary / mistakes 字段，把现象
   归类——不成膜 / 成膜不连续 / 膜质量差（开裂、糊状）/ 产物异常。
2. **证据对齐**：该组历史记录（read_experiment_records）+ 图谱失败语料
   （query_graphrag）对照，找"同单体组/同条件"的历史先例。
3. **变量逐一过**：温度/时间/催化剂浓度/溶剂体系/单体纯度/操作步骤（按
   reaction 条件字段），结合席夫碱可逆成键与结晶成膜机理判断每个变量的
   影响方向；有 DFT 数据时（query_dft）结合结合能/能隙佐证。
4. **给出假设而非断言**：每个归因都标注置信度（高/中/低）与证据来源；
   区分"模型先验"与"历史事实"。
5. **下一步建议**：给 2–3 条按优先级排序的改进方向（条件调整/换单体/
   查文献先例），提示可生成方案卡或发起深度研究。
