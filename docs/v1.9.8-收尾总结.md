## 一、这一批交付了什么（v1.9.7 → 当前 HEAD，60 个提交）

### R1 · 统一「科研知识库」（替代并列的「文献库」）
- 三栏导航壳（集合树/标签 · 服务端检索列表 · 解析状态徽标）驱动文献卡片**五页签**：
  **原文信息 / 文献图片(N) / 笔记 / 关联（引用·被引·相似 + 来源分层说明）/ 结构化条目(M)**
- 文献录入收进工具栏「＋添加文献」；**新入库文献立即镜像进 DB**（不再等重建）

### R2 · 文献阅读模块（侧栏「我的」之上）
- **阅读器**：pdf.js（翻页/跳页/缩放/文字层）+ **目录大纲** + **全文查找** + **整页双语对照**
- **划选即用**：选中文字 → 自动填入翻译框、批注页码与归一化坐标
- **翻译**（DeepSeek）：段落批量 + 段落缓存 + **DOI/SMILES/化学式/数字单位保护** + COF 术语校正
- **提问**：上下文 = 摘要 + 选中段 + 结构化条目 + 图表标注；要求标注依据、不得编造
- **批注**：高亮（四色，**画回原文**）+ **区域截图**（拖框 → 裁图 → 缩略图 → 大图）+ **一键导出 Markdown 笔记**
- **先读后入库**：外部 PDF → 收件箱（sha1 去重、不占编号）→ 一键入库（抽元数据→建条目→挂主文）
  → 「提取解析并入库 / 补全缺失解析」（二次确认）→ 阅读状态机（待读/在读/已读/已入库）
