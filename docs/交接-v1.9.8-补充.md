## 2. 这 51 个提交做了什么

### R1：合并为单一「科研知识库」入口（取代并列的「文献库」）
三栏导航壳（集合树/标签 + 服务端检索列表 + **解析状态徽标**）驱动下方文献卡片**五页签**：
**原文信息 / 文献图片(N) / 笔记 / 关联（引用·被引·相似，带来源分层说明）/ 结构化条目(M)**；
录入收进工具栏「＋添加文献」；新入库文献**立即镜像进 DB**（不再等重建）。

### R2：文献阅读模块（侧栏「我的」之上）
- **阅读器**：pdf.js（翻页/跳页/缩放/文字层）+ **目录大纲** + **全文查找**（跨页扫描、命中列表跳转）
  + **整页双语对照**（左原文右译文，段落级、后端缓存）
- **翻译**：DeepSeek，段落批量 + 缓存 + **DOI/SMILES/化学式/数字单位保护** + COF 术语校正
- **对该文献提问**：上下文 = 摘要 + 选中段 + 结构化条目 + 图表标注；要求标注依据、不得编造
- **批注**：高亮（四色，**画回原文**）+ **区域截图**（拖框 → 裁图 → 缩略图 → 点击看大图）
  + 一键**导出为 Markdown 笔记**
- **先读后入库**：外部 PDF → 阅读收件箱（sha1 去重、不占编号）→ 一键入库（抽元数据→建条目→挂主文）
  → 右栏「提取解析并入库 / 补全缺失解析」（二次确认，避免误烧 token）
- **阅读状态机**：待读 / 在读 / 已读 / 已入库；清单**优先显示带 PDF 的文献**

### C1–C5：补齐相对 Zotero 生态的弱点（后端 + API + UI 三层打通）
| 项 | 内容 | UI 位置 |
|---|---|---|
| C1 | **RRF 混合检索**（vector + graph 两路 `Σ1/(k+rank)` 融合；三态切换；逐条来源标注；向量缺失自动降级） | 检索框旁「全文/向量/图谱/混合」下拉 + 行内来源徽标 |
| C2 | **引用图分析**（PageRank 被引权重 / 社区发现 / 桥梁文献 / 时间线；缓存 + 物化上限） | 「引用图分析」卡片 |
| C3 | **OpenAlex / Semantic Scholar 补全**（被引量、只补空 year/journal、逐字段来源、节流幂等、失败容忍） | 「补全元数据」按钮（确认框显示真实缺失数） |
| C4 | **受限只读图查询 DSL**（neighbors/path/by_entity/by_metric/cites_of/top + 自然语言→DSL 仅限白名单） | 「图查询」卡片 |
| C5 | **图谱导出**（Obsidian JSON Canvas / GraphML / **离线自包含 HTML**；depth+max_nodes 防爆炸） | 「导出图谱…」下拉 |
