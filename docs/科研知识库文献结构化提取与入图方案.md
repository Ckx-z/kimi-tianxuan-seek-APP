# 科研知识库：文献录入 + 图谱 + LLM 结构化提取 + 知识图谱接入 —— 方案设计文档

> 状态：**方案稿（待用户最终确认后开发）**。
> 决策记录（与用户两轮讨论确定）：
> 1. 「文献录入」与「文献图谱」合并为统一「科研知识库」；
> 2. 设置页新增「文献解析 LLM」独立卡（独立 key，与助手 LLM/联网搜索隔离）；
> 3. 入图范围：monomer_pair + film_outcome 进侧车图，condition/characterization
>    作为属性附在反应节点上；**并扩展提取维度**（见 §2）；
> 4. embedding：本地离线 **BAAI/bge-m3**（ModelScope 直下，
>    dphuanjing + sentence-transformers），在线提供方（DashScope
>    text-embedding-v4 / MiniMax embo-01）留作可切换、默认关；
> 5. 历史文献补提取：按需单篇、一次解析全维度、审核后入库入图，不做批量；
> 6. 图谱图片（spectra 等）作为「可选附件」关联到对应表征条目。

---

## 一、设计目标

把「文献录入 → 图谱上传」重构为**科研知识库实时扩充**闭环：

```
文献（DOI/标题/PDF）
  → 元数据审核（沿用现有）
  → LLM 结构化解析（文献解析 LLM，独立配置）
  → 结构化审核（按实验组分组，逐条确认/编辑/删除）
  → 确认入库：
     ① paper_titles.json（元数据，沿用）
     ② knowledge_entries.jsonl（结构化条目，新）
     ③ 侧车图增量（graph_user.pkl 兼容，新 src/literature/graph_ingest.py）
     ④ 向量索引增量（本地 BAAI/bge-m3；未配置时跳过，图检索兜底）
     ⑤ 图谱附件（可选，关联表征条目）
  → 联动：打分验证 / GNN 反馈队列 / 本机 DFT 重算对照
```

## 二、结构化提取 schema（分层，全部带 group_id 与 evidence）

### 2.1 实验组分组（回应早期项目日志的坑）

**一篇文献含多组实验**（不同单体组合/条件，如 TFPT+B5、TFPT+B6、不同溶剂
体系）。提取 prompt 强制要求：**先识别文献中共有几组实验，逐组编号**；
所有条目必须挂 `group_id`（文献内编号，如 G1/G2/D3）与 `experiment`
组描述。审核 UI 按组聚合展示，防止跨体系数据污染（对应历史记录中
「B5 溶解度差、多条件混杂」一类问题）。

### 2.2 条目 schema（`user_data_root()/literature/knowledge_entries.jsonl`）

```jsonc
{
  "entry_id": "ke_<uuid12>",
  "paper_id": "L042",
  "group_id": "G2",                          // 文献内实验组编号（必填）
  "experiment": "TFPT+B5 管壁扩散成膜（苯胺 3eq 调制）",  // 组描述
  "kind": "monomer | monomer_pair | film_outcome | condition | "
          "characterization | property | conclusion | dft",
  // kind 相关字段：
  "monomer_smiles": "...",                    // monomer
  "monomer_role": "aldehyde|amine|other",
  "monomer_cas": "341-58-2",                  // 有则提
  "ald_smiles": "...", "amine_smiles": "...", // monomer_pair / film_outcome
  "stoichiometry": "3:2",                     // monomer_pair
  "topology": "hcb",                          // monomer_pair
  "synthesis_method": "管壁扩散-调制剂",        // monomer_pair / condition
  "film_label": 1.0 | 0.5 | 0.0,              // film_outcome（含负样本！）
  "conditions": {"solvent": "...", "temperature": "...",
                 "catalyst": "...", "modulator": "...", "time": "...",
                 "atmosphere": "..."},        // condition
  "technique": "PXRD|FTIR|BET|SEM|TEM|AFM|PL|UVVis|NMR|TGA|XPS|"
               "contact_angle|separation_flux|separation_selectivity|"
               "mechanical|photocatalysis|electrochem|dft",  // characterization
  "sample": "TFPT-B5 膜",                     // characterization：强关联到组/体系
  "metrics": [                                // 数值化，可跨文献检索对比
    {"name": "PLQY", "value": 41.3, "unit": "%"},
    {"name": "比表面积", "value": 1234, "unit": "m²/g"}
  ],
  "conclusion": "高结晶 AA 堆积 / 连续无缺陷膜",  // characterization/property/conclusion
  "property_name": "荧光性能",                 // property
  "dft_method": "B3LYP/6-31G(d,p)",           // dft
  "dft_target": "二聚体结合能",                // dft
  "evidence": "原文依据句（≤200 字，必填）",
  "figure_ids": ["fig_xxx"],                  // 关联图谱附件（可选）
  "source": "llm_extract|manual",
  "status": "pending|confirmed|rejected",
  "graph_indexed": false,                     // 入库时由 graph_ingest 回写
  "created_at": "..."
}
```

### 2.3 表征 technique 清单（13+2 类，用户确认）

PXRD / FTIR / BET / SEM / TEM / AFM / PL / UV-Vis / TGA / NMR / XPS /
接触角 / 分离通量（separation_flux）/ **分离选择性（separation_selectivity，
截留率 % + 选择性系数 α，按污染物类型细分：染料/盐/新污染物 PFAS、抗生素等）** /
机械性能 / 光催化·电化学等应用 / **DFT 计算（dft：结合能/吸附能/能级
HOMO-LUMO·Eg + 泛函基组，与本机 xTB/psi4 重算对照联动）**。

### 2.4 分层

- 第 1 层 体系：monomer / monomer_pair / condition / film_outcome（含负样本）
- 第 2 层 表征：characterization（technique + metrics 数值化）
- 第 3 层 性能：property
- 第 4 层 结论：conclusion（成膜机理/构效关系）
- 第 5 层 附件：图谱图片关联对应条目（figure_ids）

## 三、文献解析 LLM（独立配置）

- 设置页新卡「文献解析 LLM」：base_url / api_key / model + 测试连接 + 开关
  （默认关；关闭时 PDF 提取降级为现有 RDKit 正则扫描）。
- 存储：`config/literature_llm_settings.local.json`（gitignored，key 只回显
  掩码，参照 search-settings 机制）；服务：`src/literature/llm_extract.py`
  （prompt = 识别实验组 → 逐组输出 JSON；每条必须带 evidence；输出超长
  分段再合并；失败自动重试 1 次）。
- 与助手 LLM / 联网搜索 key 完全独立，可配不同模型（如便宜快速的模型）。

### embedding 提供方（文献解析设置内，三态可切换）

| 提供方 | 实现 | 状态 |
|---|---|---|
| 关（默认） | 不向量化；图路径检索 + 文本匹配兜底 | ✅ 零依赖 |
| 本地离线 | dphuanjing + sentence-transformers 加载 **BAAI/bge-m3**（HF 镜像下载到 E:\\cof_models\\bge-m3，约 2.2GB，1024 维；dphuanjing 为 Python 3.8，Qwen3 系列要求 transformers≥4.51 不支持 3.8，故选 bge-m3）；配置字段：解释器=gnn_python、模型路径/名称 | ✅ 推荐上线时配置 |
| 在线 | DashScope text-embedding-v4 / MiniMax embo-01（key 在文献解析设置中填写） | 可选 |

- 文献向量库独立存储：`user_data_root()/graphrag_user/literature_emb.jsonl`
  （entry_id + vector + meta），与旧 knowledge_index（1536 维）互不干扰，
  检索时新旧各查再合并。
- 安装脚本：`scripts/install_lit_embedding.bat`（dphuanjing pip 装
  sentence-transformers + modelscope 下载 BAAI/bge-m3）。

## 四、知识图谱接入（复用侧车图，秒级生效，不重建包内图）

新 `src/literature/graph_ingest.py`（沿用 minimax/bridge/user_graph.py 的
节点 ID 方案，保证与包内图对齐）：

- `monomer` → `M-<md5(SMILES)>` 节点（已存在则复用）+ monomer 属性
  （role/cas）
- `monomer_pair` / `film_outcome` → `LIT-<paper_id>-<group_id>` 节点
  （node_type='reaction'，source='literature'，附 stoichiometry/topology/
  method/conditions/evidence）+ 边 `reaction_uses_aldehyde` /
  `reaction_uses_amine` + 成膜结论边 `reaction_produces` → O-film /
  O-partial / O-failed（负样本挂 O-failed）
- `characterization` / `property` / `dft` / `conclusion` → 作为对应反应节点
  的属性（technique/metrics/conclusion 列表），不进新节点
- 确认入库时同步写入（同 user_graph.append_records 口径）；助手
  query_graphrag / 方案迭代的图加载处接线 `merge_into`（确认现有加载点，
  若未 merge 侧车图则补上）→ 文献条目即时可检索。

## 五、前端（Mine 页统一「科研知识库」）

- 一个 Section、一篇文章一张卡：卡头元数据 + 徽章（已入图 / 结构 n 条 /
  图谱 m 张）；卡体 Tabs：结构化条目（按 group_id 分组）｜ 图谱（画廊
  迁移）｜ 原文信息。
- 入库四步流：录入（现有三步）→ LLM 解析（自动）→ 结构化审核（分组表，
  逐条确认/编辑/删除，evidence 对照，图谱可选上传）→ 确认入库（原子）。
- 条目联动按钮：打分验证（跳转预填）/ 加入 GNN 反馈（film_outcome 直入
  反馈队列）/ **本机 DFT 重算对照**（dft 条目 → 跳 DFT 页预填，结果回写
  `score_note` 类备注）。
- 历史文献补提取：文献卡片「补解析」按钮（单篇按需）。

## 六、后端接口（literature 路由扩展）

| 方法/路径 | 说明 |
|---|---|
| `POST /api/literature/{paper_id}/parse` | 触发 LLM 全维度解析（PDF 全文或已有原文）→ 返回分组条目预览（不落库） |
| `POST /api/literature/{paper_id}/entries` | 审核后的条目批量入库（元数据+条目+侧车图+向量，原子） |
| `GET /api/literature/{paper_id}/entries` | 条目列表（按 group_id 分组） |
| `PATCH/DELETE /api/literature/entries/{entry_id}` | 编辑/删除（删除同步撤侧车图节点） |
| `GET /api/literature/entries?kind=&technique=&film_label=` | 跨文献条目检索（含数值范围查询 `metric.name` + min/max） |
| `GET /api/literature/llm-settings` / `PUT` | 文献解析 LLM 与 embedding 提供方配置 |
| `POST /api/literature/llm-settings/test` | 测试连接 |
| `POST /api/literature/entries/{entry_id}/to-gnn-feedback` | film_outcome 条目 → GNN 反馈队列 |
| `POST /api/literature/entries/{entry_id}/to-dft` | dft 条目 → DFT 预填（返回跳转参数） |
| `GET /api/literature/embedding-status` | 本地/在线 embedding 可用性 |

**数值检索**：`GET /entries` 支持 `metric=PLQY&min=20`、`film_label=1`
等过滤（供助手与前端「跨文献找数据」）。

### 验证标准

- [ ] 一篇含多组实验的文献：解析结果按 group_id 正确分组，无跨组数据污染；
- [ ] film_outcome 负样本（label=0）与正样本都正确入库并挂图；
- [ ] 确认入库后助手 query_graphrag 能检索到该文献条目（侧车图 merge）；
- [ ] 数值检索：`PLQY>20%` 能跨文献查到对应条目；
- [ ] dft 条目「本机重算对照」跳 DFT 页预填正确；
- [ ] film_outcome 一键进 GNN 反馈队列；
- [ ] embedding 三态切换正确；关态下图检索兜底可用；
- [ ] 全套 pytest 保持全绿（新增用例 ≥25）。
