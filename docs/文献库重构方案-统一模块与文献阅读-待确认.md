## B. 新增「文献阅读」模块（侧栏在「我的」之上）

### 定位
对标 Zotero 的**阅读器 + 阅读状态机**：把一个 PDF 读进来、读的时候做批注、读完把内容**送进科研知识库**
（没有条目就建、没有解析就解析、缺什么补什么）。

### 页面结构

```
文献阅读
├─ 左栏「阅读清单」
│   ├─ ＋上传 PDF（可多份：主文 + SI；拖拽/选择）
│   ├─ 从文献库选取（搜索 + 勾选，支持一次加入多篇）
│   └─ 清单分组：待读 / 在读 / 已读 / 已入库（可筛选）
├─ 中栏 PDF 阅读器（pdf.js）
│   ├─ 翻页 / 缩放 / 目录 / 全文搜索 / 双页
│   └─ 批注：高亮（多色）、便签、区域截图 → 自动写入右侧
└─ 右栏
    ├─ 本文信息：标题/DOI/年份 + **解析状态检查表**（摘要·结构化条目·文献图片·附件 四项）
    ├─ 批注与笔记：列表（点击跳回原文位置）+ 手动笔记（Markdown）
    └─ 入库动作：
         · 未入库 → 「提取解析并入库」（解析 → 预览勾选 → 入条目/图/摘要）
         · 已入库但缺项 → 「补全缺失解析」（**只跑缺的那几项**：摘要 / 条目 / 文献图）
```

### 数据与接口（新增，向后兼容）
- 表：`item_annotations`（对齐 Zotero `itemAnnotations`：`annotation_id, paper_id, attachment_id,
  type(highlight|note|image), page, position_json, color, text, comment, created_at`）
- 表字段：`reading_state`（unread / reading / read / ingested）→ 落在 `items.extra_json` 或独立列
- API：`POST/GET/PATCH/DELETE /api/library/annotations`（按 paper/attachment 过滤）、
  `POST /api/library/reading/state`、`GET /api/library/reading/queue`、
  `POST /api/library/reading/ingest`（参数 `paper_id`, `parts=[meta,entries,figures]`, `force=false`）
- 复用：`/parse`（多文件）、`/figures/import`、`/papers` PATCH 回填、`pdf_figures` 抽图、
  `vision`（可选）、`knowledge.add_entries`（试校验 + 人工勾选）

### 关键行为（用户明确要求的两条）
1. **外部上传也能读**：上传 PDF → 立即进入阅读清单（状态"待入库"）→ 读完可一键「提取解析并入库」；
   若 PDF 已有 DOI 可自动抓元数据，无 DOI 允许手填 → 入库时按现有规则分配编号（1782 起）。
2. **已有文献只补缺**：从文献库选入 → 打开即做**状态检查**（摘要/条目/图/附件），
   「补全缺失解析」只执行缺失项，**不重复解析已有内容**（与现有"只补空字段"语义一致）。

## C. 补齐相对 Zotero 生态的 5 项弱点

| # | 弱点 | 我们的方案 | 工时 | 批 |
|---|---|---|---|---|
| C1 | 检索只有启发式拼接，没有混合检索融合 | **RRF 融合**：vector（bge-m3）+ graph（cites/similar/实体）两路召回按 `Σ 1/(k+rank)` 融合；界面三态 `vector/graph/hybrid`；命中带**来源标注**（哪条边贡献的） | 6–8h | R3 |
| C2 | 没有图算法与全局引用指标 | NetworkX 按上限物化子图 → **PageRank / 社区发现 / 桥梁文献 / 最短路径 / 时间线**；结果缓存进 `graph_nodes.meta_json` | 8–10h | R3 |
| C3 | `cites` 只有逐篇 Crossref 的本地视角 | 接 **OpenAlex / Semantic Scholar**（免 key）补 `cited_by`、被引量、年份分布、领域标签；带限速与磁盘缓存（对齐 zotero-refs 的多源融合 + 逐字段来源标注） | 6–8h | R4 |
| C4 | 没有图查询语言 | 受限 DSL（白名单算子：`neighbors / path / by_entity / by_metric / cites_of`）+ 自然语言→DSL 的 LLM 翻译（只读、可解释、拒写）。**不引 Kuzu（已归档）与 Neo4j（JVM/GPLv3）** | 10–14h | R4 |
| C5 | 图谱无法导出 | **JSON Canvas / GraphML / D3 HTML** 三种导出（对齐 citation-atlas 与 zotero-mcp）+ 防爆炸参数（一层深、上限可配） | 4–6h | R5 |

**边界（仍不做）**：云同步 / 群组库 / 多用户 · Word 插件（改为"一键复制引文：GB/T 7714、APA"）· 浏览器插件（改为"粘贴 DOI/URL 抓取"）。

```
R1（合并统一）─► R2（文献阅读；"从文献库选取"依赖 R1 的列表）
R3（RRF + 图算法）· R4（OpenAlex + 图查询）· R5（导出）  ← 后端独立，可与 R2 并行
```
