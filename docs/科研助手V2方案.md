> 2026-08-24 起草。状态：**待用户审查**，确认后开工。
> 前置：V1（v0.3.0）已上线——双路径工具循环（function calling + 降级）、ming 人格、三工具（predict_film / query_graphrag / read_experiment_records）、SSE 对话、附件上传（v0.3.1 修复加入）。

## 一、V1 的缺口

| 缺口 | 影响 |
|---|---|
| 工具只有 3 个 | 让它"收藏这组单体""生成方案卡"都做不到，只能读不能写 |
| 无跨会话记忆 | 每次对话从零开始，不知道用户上周踩过什么坑 |
| 无主动摘要 | 实验记录和迭代历史散落在各处，助手不会主动汇总 |
| 单轮问答感强 | 缺任务式多步执行（"帮我把这 5 组单体都打分并排序"） |

## 二、V2 目标（一句话）

**从"会查资料的问答机器人"升级为"能动手、有记忆的科研搭档"。**

## 三、功能设计

### 3.1 工具集补全（读 → 读写闭环）

| 新工具 | 类型 | 说明 |
|---|---|---|
| `manage_favorite` | 写 | 收藏/取消收藏单体组合，放入指定收藏夹（配合 v1.0.0 收藏夹体系） |
| `generate_plan_card` | 写 | 按模板生成实验方案卡（复用 plan 管线），可指定模板 |
| `list_favorites` / `list_history` | 读 | 查收藏夹内容、查询打分历史记录 |
| `query_dft` | 读/写 | 查 DFT 计算缓存结果 / 提交 DFT 计算任务（依赖 v1.0.0 P3，接口先行预留） |
| `search_literature` | 读 | GraphRAG 文献库检索的轻量封装（按关键词/单体名直查文献条目） |
| `draft_experiment_record` | 写 | 根据对话内容起草实验记录（存草稿态，用户确认后转正） |

写类工具统一走**二次确认**：助手先说"我准备做 X，确认吗"，用户点确认才执行（前端在工具事件卡上加确认按钮）。

### 3.2 记忆编译（Memory Compilation）

- **会话级**：当前会话超 20 轮时自动摘要压缩早期轮次（保留工具结果要点）
- **用户级（本机）**：每次会话结束时，LLM 提炼"值得记住的事"写入 `user_data_root()/assistant/memory.md`——如"用户对苯二胺+均苯三甲醛组合两次成膜失败，倾向换溶剂体系"；下次会话开局自动注入（截取前 N 条）
- 设置页加「助手记忆」开关与"查看/清空记忆"按钮（用户数据自主权）

### 3.3 主动能力

- **实验日报卡**：助手页顶部可选生成"今日/本周实验进展摘要"（聚合实验记录+迭代历史+打分历史，一键导出 markdown）
- **异常提醒**：读取最新实验记录后，若某组合连续失败 ≥2 次，助手开场白主动提及并给排查方向

### 3.4 附件理解深化（V1 已有基础上）

- 上传的实验照片接入视觉模型解读（"这张图看起来膜连续性如何"）
- 上传文献 PDF → 提取方法与结论入库 GraphRAG 侧车图（打通"我的文献"）

## 四、技术要点

- 工具确认机制：SSE 事件流新增 `tool_confirm` 事件类型；确认结果作为工具输入回注
- 记忆注入位置：system prompt 尾部，与 persona/领域规则分层（persona > 领域纪律 > 记忆 > 工具说明）
- 记忆防膨胀：memory.md 超 100 条时 LLM 合并去重
- 全部写操作落 user_data_root，不进分发包

## 五、分期

| 期 | 内容 | 依赖 |
|---|---|---|
| **V2.0** | 工具集补全（3.1 中除 query_dft 外）+ 写操作二次确认 + 会话级记忆压缩 | 无，可直接开工 |
| **V2.1** | 用户级记忆编译 + 记忆开关/查看/清空 | V2.0 |
| **V2.2** | 实验日报卡 + 异常提醒 + query_dft 接入 | v1.0.0 P3（DFT）完成后 |
| **V2.3** | 附件理解深化（视觉解读、PDF 入图） | 视觉模型配置率足够时 |

## 六、验收标准

- "帮我把收藏夹1里没打分的组合都打分并按概率排序" → 助手多步调用 list_favorites → predict_film ×N → 汇总表格回答
- "把上次对苯二甲醛那组收藏到收藏夹1" → 二次确认卡 → 执行成功
- 第二天新开对话问"我最近实验怎么样" → 助手能引用记忆与记录回答
- 全部写操作未确认不执行；记忆可一键清空
