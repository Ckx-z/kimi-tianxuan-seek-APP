# v1.9.8 验收清单（装上后照此逐项点）

> 用途：安装 v1.9.8 后，按下面三条动线验收。每条都写清**点哪里 → 应看到什么 → 过了什么算通过**。
> 有任何一项不符，直接把该步截图发我，我按图定位。

---

## 0. 验收前（1 分钟）

| 步骤 | 期望 |
|---|---|
| 安装 `cof-film-recommend-setup-1.9.8.exe`（UAC 需批准） | 安装完成，桌面图标可启动 |
| 启动应用，打开「设置」 | 版本三显均为 **1.9.8** |
| 打开「我的」 | 页面可滚动到「科研知识库」区块（不再有并列的「文献库」区块） |

---

## 1. 动线 A：统一知识库（R1）

| # | 操作 | 应看到 |
|---|---|---|
| A1 | 「我的 → 科研知识库」，左栏点「未分类」 | 中栏列出文献（计数应约 1711）；每行右侧有 **未解析 / 部分解析 / 已解析** 徽标，带「缺 N 项」 |
| A2 | 中栏顶部检索框输入 `SPME` | 命中即时收窄（服务端 FTS） |
| A3 | 检索框右侧下拉切到「**混合（RRF）**」 | 立刻出现「正在做混合检索…（首次会加载本地向量模型，可能 30–60 秒）」；**列表清空**（不再显示旧结果）；数十秒内出现结果，**每行带「图谱」/「向量」来源徽标与 RRF 分值** |
| A4 | 点中栏任一文献 | 下方卡片出现五个页签：**原文信息 / 文献图片(N) / 笔记 / 关联(M) / 结构化条目(M)** |
| A5 | 点「**关联**」页签 | 显示 引用 / 被引 / 相似 三组（带 DOI 外链与相似度），底部有「Crossref 命中=确证引用；向量近邻=算法推荐」说明 |
| A6 | 点「**笔记**」页签 → 写一条笔记 → 保存 | 笔记出现在列表，标注「手动」；刷新后仍在 |
| A7 | 点右上「**＋ 添加文献（DOI / 标题 / 上传 PDF+SI）**」 | 录入区展开；再点一次收起 |

## 2. 动线 B：文献阅读（R2）

| # | 操作 | 应看到 |
|---|---|---|
| B1 | 侧栏「**文献阅读**」（位于「我的」之上） | 左栏清单**优先显示带 PDF 的文献**；每行有 待读/在读/已读/已入库 与解析状态徽标 |
| B2 | 点左栏一篇带 PDF 的文献 | 中栏出现 **PDF 阅读器**（画布渲染，不是浏览器默认查看器），工具条有 翻页/跳页/缩放/目录/查找/截图/双语 |
| B3 | 点「**目录（N）**」 | 下拉列出章节，点击可跳页 |
| B4 | 点「**查找**」→ 输入 `COF` → 搜索 | 列出命中页与上下文片段，点击跳页 |
| B5 | 在正文里**用鼠标划选一句话** | 工具条右侧提示「已选中 N 字（第 X 页）→ 已填入右侧翻译/批注框」；右侧翻译框出现该句、批注页码自动填好 |
| B6 | 点「**翻译为中文**」（右侧「翻译 / 提问」块） | 数十秒内出现中文译文；若同段再次翻译会提示「N 段命中缓存」 |
| B7 | 右侧「就这篇文献提问」输入问题 → 回车 | 回答基于该文献（摘要/条目/选中段），并标注来源类别；材料不足时会明说 |
| B8 | 点「**双语对照**」 | 右侧浮出**左原文 / 右译文**对照栏（当前页，段落级） |
| B9 | 点「**截图**」→ 在页面上**拖一个框** | 提示「区域截图已存为批注」；右侧批注列表出现**缩略图**；点击缩略图可看大图 |
| B10 | 划选一句 → 点「添加批注」（选颜色/写评论） | 批注列表新增；**页面上该处出现高亮块** |
| B11 | 点「**批注导出为笔记**」 | 提示成功；回到「科研知识库 → 笔记」页签可看到含页码与引文的 Markdown 笔记 |
| B12 | 左侧虚线区「**上传 PDF 到这里阅读**」选一份外部 PDF | 出现在收件箱（标「待入库」），点开即读；**未占用库编号** |
| B13 | 读完后点「**读完入库（建条目 + 挂附件）**」→ 确认 | 提示「已入库：文献 #<编号>（已挂主文附件）」；编号 ≥ 1782；该文献出现在科研知识库中 |
| B14 | 右栏点「**提取解析并入库 / 补全缺失解析**」→ 确认 | 明确告知将执行全量解析或只补缺项；执行中显示「解析中…」；完成后解析状态更新为「已解析」，阅读状态→已入库 |

## 3. 动线 C：图谱能力（C1–C5）

| # | 操作 | 应看到 |
|---|---|---|
| C1 | 科研知识库右上「**补全元数据**」 | 确认框显示「当前 **N** 篇缺少年份…每次最多 20 篇、免费无需 key、约 1 秒/篇」；执行后缺年份数减少，年份/期刊被回填（**已有值不被覆盖**）|
| C2 | 右上「**导出图谱…**」→ Obsidian 画布 | 下载 `.canvas` 文件，可拖入 Obsidian 打开 |
| C3 | 同上 → GraphML | 下载 `.graphml`，可用 Gephi/yEd 打开 |
| C4 | 同上 → 离线可交互页面 | 新窗口打开图谱：**可拖拽节点、滚轮缩放、悬停看标题**（无网络也能用） |
| C5 | 下方「**引用图分析**」卡片 | 四块内容：被引权重 Top（PageRank）· 研究簇（社区）· 桥梁文献 · 时间线；点「重算」可强制刷新 |
| C6 | 右下「**图查询（只读 DSL）**」→ 输入 `top pagerank limit=5` → 回车 | 返回排行结果；试 `neighbors 1529 depth=1 pred=cites` 返回邻域；试 `drop table items` **应被拒绝** |
| C7 | 勾选「自然语言」→ 输入「和 1529 相关的文献有哪些」→ 执行 | 先显示「已翻译为：neighbors …」，再给出结果 |

## 4. 已知限制（不是缺陷，验收时不必报）

| 现象 | 说明 |
|---|---|
| 首次「混合检索」/首次翻译较慢 | 需加载本地向量模型 / 调云端模型；应用启动已做**后台预热**（首搜从 30–60s 降到约 13s） |
| 学科指标名多为英文 | 已加**中英同义词**：`比表面积`/`孔径`/`峰位` 等中文可直接命中英文指标行 |
| 扫描版 PDF 划选无文字、双语提示"本页没有可取文字" | 需先做 OCR（后续可接视觉模型） |
| 时间线年份较少 | 该库多数条目缺 `year` → 用「补全元数据」从 OpenAlex 批量补齐 |
| 翻译/解析会产生费用 | 均需二次确认；翻译同段命中缓存不重复计费 |

## 5. 不通过时怎么给我信息（最有用）

1. **截图**（整窗，含左下角版本号）+ 你点的那一步编号（如 B9）
2. 若涉及后端：`%APPDATA%\COF-Film-Recommend\` 下的日志
3. 若界面错乱想回退：`scripts\rollback_ui.ps1 -List` 看快照 → `-Snapshot <名字>` 恢复
4. 若是"安装后没反应"：先确认 `cof-backend` 进程是否起来（任务管理器），并把安装包体量告诉我
   （正常 **464 MB**；若你拿到的是 ~142 MB 的包，说明踩到了已修复的打包守卫问题，请重下）
