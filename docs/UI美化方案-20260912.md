# UI 美化方案（v1.9.3 问题 6，待用户确认后实施）

> 目标：在不改变任何功能、数据流与交互语义的前提下，把界面从「功能可用」提升到
> 「精致、统一、有呼吸感」。所有改动限于样式与布局层（Tailwind class / CSS 变量 /
> 局部组件结构），**不动 API、不动状态逻辑、不动 Electron 壳**。

---

## 一、现状诊断（走查结论）

| 问题 | 具体表现 | 影响 |
|------|----------|------|
| 设计令牌零散 | 颜色/圆角/阴影/间距直接写死在 className 里（`rounded-lg`、`border-border`、`bg-muted/40` 混用），无统一 scale | 同类元素视觉不一致，改一处漏一处 |
| 层级表达弱 | 页面 = 一串同权重 Card；标题、副标题、说明文字字号/颜色梯度不明显 | 视线无落点，信息密度感重 |
| 留白节奏乱 | `p-3 / p-4 / px-4 py-2` 混用；卡片间距 `gap-2 / gap-3 / gap-4` 随机 | 页面显得「拥挤且不齐」 |
| 状态样式不统一 | 空态、加载（Skeleton）、错误、成功提示各页各写一套 | 体验碎片化 |
| 交互反馈单薄 | hover/focus/active 多为默认；focus ring 不统一；按钮 loading 态样式各异 | 显得「不像成品软件」 |
| 深色与主题 | 紫金主题变量只在少量组件生效，`dark:` 覆盖不全 | 明暗切换后部分区域刺眼 |
| 表格/图表密度 | 收藏表格、记录列表行高与字号偏大或偏小不统一 | 数据页浏览效率低 |

---

## 二、设计原则（本次改版的边界）

1. **信息架构不动**：不新增/删除功能入口，不调整页面路由与字段。
2. **紫金主色不变**：延续现有 `primary`（紫）+ `gold` 双色体系，只做明度/饱和度收敛与用法规范。
3. **令牌先行**：先建立统一的 design tokens，再让组件消费令牌，避免"逐页刷 class"。
4. **克制**：不使用大面积渐变、发光、重阴影；研究工具应显专业与安静。
5. **可回退**：每批改动独立提交，任何一批可单独回滚。

---

## 三、令牌化（第一批，基础层）

### 1. 颜色与语义变量（`webapp/src/index.css` + `tailwind.config`）

- 收敛语义色：`--surface`（卡片）/`--surface-muted`（次级面板）/`--border`/`--border-strong`/`--fg`/`--fg-muted`/`--fg-subtle`；
- 状态色统一：`success / warning / danger / info` 四组（各含 `bg / border / fg` 三个代表色），替换散落的 `emerald-*`、`amber-*`、`red-*`、`green-*`；
- 金色只用于「重点/成就/科学强调」（如成膜成功、金色分隔线、主 CTA 描边），不再大面积铺底。

### 2. 尺寸与节奏

- 圆角阶梯：`sm=6 / md=10 / lg=14 / xl=18`（现有 `rounded-lg` 语义映射到 md）；
- 阴影三级：`shadow-card`（静态卡片）/`shadow-pop`（悬浮、弹窗）/`shadow-none`；
- 间距阶梯：`4 / 8 / 12 / 16 / 24 / 32`，卡片内边距统一 `p-4`（紧凑场景 `p-3`）；
- 字号阶梯：`text-[11px] 辅助 / text-xs 说明 / text-sm 正文 / text-base 小标题 / text-lg 页面标题`，并用字重（`font-medium/semibold`）表达层级而非仅靠字号。

### 3. 交互统一

- focus：统一 `focus-visible:ring-2 ring-gold/50 ring-offset-1 ring-offset-background`；
- hover：卡片 `hover:border-border-strong hover:shadow-card`，行 `hover:bg-accent/40`；
- disabled：`opacity-50 cursor-not-allowed` 全局一致；
- 过渡：统一 `transition-colors duration-150`，避免各组件 `transition-all`。

---

## 四、组件层（第二批）

| 组件 | 改动 |
|------|------|
| `Card / CardHeader / CardContent` | 增加 `variant: default / muted / interactive`；标题区统一「图标 + 标题 + 右侧动作」三栏 |
| `Button` | 统一 4 个 variant 的 hover/active/focus；新增 `loading` 态（内置 Loader2 + 文案保持） |
| `Badge` | 语义色对齐状态令牌；新增 `dot` 前缀样式（状态点 + 文本） |
| `Tabs` | 下划线指示器统一金色细线；页签内边距对齐 |
| `Dialog` | 标题区留白加大、底部按钮右对齐间距统一、滚动区加顶部淡出遮罩 |
| `Table` | 表头 `bg-surface-muted/60 sticky`、行高 40/36 两档、数字列右对齐 |
| `Skeleton / EmptyState`（新增） | 统一骨架屏节奏与空态插画位（图标 + 一句话 + 可选主行动按钮） |
| `Toast` | 统一图标颜色与最大宽度，成功/失败/警告视觉分级 |
| `Resizer`（本版已加） | 加入 hover 高亮与键盘提示，视觉与主题一致 |

## 五、页面级（第三批，按收益排序）

1. **科研知识库（重点）**：文献列表 → 左列表右详情两栏；条目按组分块（组标题吸顶）；条目徽章统一；附件/SI 区域做成「文件卡」；解析预览的组与勾选层级更清晰。
2. **科研助手**：工具卡（tool_call/result）统一为「单行摘要 + 折叠详情」；报告卡与引用列表视觉分级；输入区加聚焦态与快捷键提示；侧栏与对话区宽度可拖（本版已实现，纳入统一视觉）。
3. **首页仪表盘**：卡片网格统一间距与高度；数字型信息用大字号 + 单位小字；空态统一。
4. **实验记录**：时间线改为「竖向时间轴 + 节点」（左侧时间、右侧描述、附件小图标）；草稿/正式状态用左边框色区分；详情页分区标题统一。
5. **方案迭代**：建议卡统一为「标题 + 置信度条 + 依据摘要 + 行动按钮」；批次分组吸顶。
6. **设置页**：分组卡片化（LLM/检索/GNN/文献解析/界面），组内 label + 控件两列对齐；危险操作红色分区。

## 六、可选的体验增强（不含功能变更）

- **密度开关**：右上角「紧凑 / 舒适」切换（写 localStorage，调整 `--density` 影响行高与内边距），适合数据密集的收藏/记录页；
- **主题**：补全深色模式变量（现有 `next-themes` 已接入），使明暗切换无死角；
- **动效**：仅保留「卡片进入 120ms 淡入 + 上移 2px」「折叠展开高度过渡」，不使用弹跳/旋转等花哨动效；
- **图标**：统一 lucide 尺寸（14/16/20）与描边色，避免大小混杂。

## 七、交付批次与验收

| 批次 | 内容 | 预估工时 | 验收标准 |
|------|------|----------|----------|
| U1 基础层 | 设计令牌 + Button/Card/Badge/Tabs/Dialog/Table/Skeleton/EmptyState 统一 | 4–5 h | 全站组件视觉一致；tsc + vite build 通过；无功能回归 |
| U2 助手 + 知识库 | 两个核心页面的布局与卡片层级重做 | 4–5 h | 交互路径不变；关键操作（解析/入库/研究/上传）实测可用 |
| U3 其余页面 + 打磨 | 首页/记录/迭代/设置 + 密度开关 + 深色补全 | 4–5 h | 明暗两种主题逐页检查；表单/表格可用性不降低 |

**统一验收清单**：① 间距只出现 4/8/12/16/24/32；② 颜色只来自语义令牌；③ focus 可见且统一；
④ 每页有明确主行动；⑤ 空态/加载/错误三态齐全；⑥ `tsc`+`vite build` 通过、`pytest` 全绿；
⑦ 桌面（≥1280）与窄屏（≤768）逐页检查；⑧ 不改动 API/状态/路由（diff 只含样式与结构）。

**明确不做**：不引入新的 UI 框架或重型组件库；不做全站重构式改写；不改 Electron 主进程与打包配置；不做信息架构调整。

---

## 八、需要用户拍板的三点

1. **风格方向**：A. 学术克制（推荐，白底 + 紫金点缀 + 细边框）；B. 深色科技（默认深色 + 紫金高亮）；C. 保持现状只做一致性修补。
2. **密度默认值**：默认「舒适」还是「紧凑」？
3. **实施节奏**：U1→U2→U3 分三批验收，还是先做 U1+U2 一批（更快看到效果）？
