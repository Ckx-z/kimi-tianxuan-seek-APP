# P6 视觉能力：怎么配、能干什么、边界在哪

> 写于 v2.0.0 之后（P6 视觉批次）。**你不需要另办别家 Key** —— DeepSeek 已支持图像输入，
> 端点与 Key 和你现有解析 LLM 完全一样。

## 一、配置（30 秒，两步）

**设置 → 文献解析 LLM → 视觉读图**：

| 字段 | 填什么 | 说明 |
|---|---|---|
| 视觉读图开关 | **开启** | 不开启时所有视觉入口都会隐藏或如实报错，不会假装成功 |
| 视觉模型名 | **`deepseek-flash`** | 官方「图像理解」指南用的就是这个模型名；旧名 `deepseek-v4-flash-vision-exp` 仍可调用，但该模型已下线，请求由最新 Flash 承接 |
| 视觉模型端点 | **留空** | 留空 = 沿用上面解析 LLM 的端点（`https://api.deepseek.com`） |
| 视觉模型 Key | **留空** | 留空 = 沿用上面解析 LLM 的 Key |

保存后该卡片会显示「视觉读图可用（deepseek-flash，端点/key 沿用解析 LLM）」。

> 想换成更擅长读细图的模型（如 Qwen-VL 系）也可以：把端点/Key/模型名都填上即可，
> 我们用的是**标准 OpenAI 兼容 `image_url` + base64** 格式，换供应商不用改代码。

- [DeepSeek：V4-Flash-Vision-Exp 上线公告](https://api-docs.deepseek.com/zh-cn/news/news260821/)

## 二、配好之后能干什么

| 入口 | 做什么 | 写到哪里 |
|---|---|---|
| 文献图片 → 单张「AI 识别」 | 识别该图类型/技术/描述/可读数值 | 写回该图标注，来源标记 **视觉标注**（`caption_source=vision`）|
| 文献图片 → 「AI 识别全部」 | 批量识别（默认跳过已标注的图）| 同上 |
| 知识提取 → 「读图提取数值」 | 把图里的数值变成**可勾选的知识条目**（已有功能）| 知识库条目（`source=vision_extract`）|
| 科研助手 → 回形针上传图片 | 直接把图给助手看（谱图/结构/截图）| 仅当轮对话，不写库 |
| 科研助手 → **相机按钮** | 截取主屏画面并作为附件提问（**仅桌面版 Electron 有**）| 仅当轮对话 |
| 科研助手 → 说「看看 P12 的 XRD 图」 | 助手调 `view_figure` 读库里的图（会先二次确认，因为会产生 API 费用）| 可选写回标注 |

## 三、官方限制（我们照此实现，避免你以为"应该行"其实不行）

| 限制项 | 数值 | 我们的处理 |
|---|---|---|
| 支持格式 | JPEG / PNG / GIF / WebP（**按文件内容判断**，不看扩展名）| 附件校验只放这几种 |
| 单图大小 | 官方 ≤32 MiB | 我们更严：**>5MB 直接跳过**并说明原因（省 token 也避免超时）|
| 请求体 | ≤48 MiB | 单图上限已远低于此 |
| 图片缩放 | 自动缩放到约 **1300×1300 等效**；<544×544 会被放大 | 单图最多 1024 token |
| 图片位置 | 只能出现在 **user** 消息 | 我们只往 user 消息里放图 |
| 截图按钮 | — | 主屏物理像素、最长边封顶 **2560×1440**；PNG 超约 4MB 自动转 JPEG(85) |

## 四、诚实的边界（重要）

1. **密集谱图的精确数值不要全信**。图片会被缩放到约 1300×1300 等效，PXRD 峰位、
   截留率曲线这类密集信息在缩放后可能失真。我们的提示词强制要求
   「只写图中确实可读到的数值，读不准宁可不写」，并要求模型给出
   `confidence`（high/medium/low）与依据说明 —— 但**最终判断仍需你人工复核**，
   尤其是要写进实验记录或论文的数值。
2. **未配置视觉模型时不会假装成功**：按钮不显示；接口返回 409 并给出中文原因；
   助手会明说「看不到图」，而不是编一段描述。
3. **助手能否读你上传的图片**：只要上面配好了视觉模型，**带图的那一轮会自动切到视觉模型**
   （`chat_completion_with_tools` 检测到 `image_url` 分片就用 `vision_model` 的模型/端点/Key），
   纯文字轮次仍用你的对话模型。没配视觉模型时沿用对话模型，端点拒绝图片则降级为
   文字提示（不报错、不编造）。
4. **费用**：按 token 计费，图片最多 1024 token/张（官方口径）。批量识别 50 张图
   属于可控范围，但仍建议先用单张试。

## 五、怎么自己验证（两条路）

### A. 不花钱：用假端点验证「链路是否通」
```powershell
# 终端 1：起一个假视觉模型（固定返回一份 PXRD 分析结果）
E:\ANACONDA\python.exe .tmp_xtb\mock_vl_server.py --port 18899

# 然后把「视觉模型端点」填 http://127.0.0.1:18899/v1 ，模型名随便填，Key 随便填
# 再点某张图的「AI 识别」→ 应出现「视觉标注」徽标与描述
# 想要失败路径：加 --fail（应显示原因且不写库）或 --no-json（应提示无法解析）
```

### B. 花极少钱：用真端点验证
配好 DeepSeek 那两行后，打开任意有图的文献 → 文献图片 → 点一张图的「AI 识别」→
看是否出现「视觉标注」徽标 + 一句中文描述。失败时 toast 会给出后端原样错误
（例如 401 = Key 不对、404 = 模型名不对、429 = 限速）。

## 六、排错速查

| 现象 | 原因 / 处理 |
|---|---|
| 看不到「AI 识别」按钮 | 视觉读图开关没开，或模型名/Key 没配齐（返回设置页看卡片底部那行状态）|
| 点按钮提示 409 | 同上，后端明确拒绝：配置不完整 |
| 提示图片超过 5MB | 换小图，或先用系统截图工具裁掉无关区域 |
| 提示「模型未返回内容（可能不支持图片输入）」| 模型名填的不是支持视觉的模型（DeepSeek 请填 `deepseek-flash`）|
| 助手说看不到图 | 视觉模型没配（带图轮次已自动切到视觉模型；没配就沿用对话模型，被拒时降级提示）。按要求配好上面两行即可 |
