# DFT 后端基准验证报告（S66 子集）

> 对应《DFT后端替换方案.md》§四 步骤 5「本机基准验证」。
> 计算日期：2026-08-27；机器：本机 Windows（xTB 内置 / Psi4 1.11 @ psi4-env）。
> 结构化原始数据：`docs/benchmark_dft_results.json`；复现脚本：`scripts/benchmark_dft.py`。

## 一、目的

用 5 个 S66 基准集非共价二聚体（文献值为 CCSD(T)/CBS 金标准，Řezáč et al.
*J. Chem. Theory Comput.* 7, 2427 (2011)）检验两条计算管线的结合能精度：

- **xTB 快速档**：GFN2-xTB 几何优化（`src/dft/engine.py`）
- **Psi4 精度档**：ωB97X-D3BJ/def2-SVP + counterpoise BSSE 校正（`src/dft/psi4_backend.py`）

## 二、两个口径（重要）

基准过程中发现：**管线默认的 UFF 复合物初猜对取向敏感**，是误差的主要来源。
因此报告分两个口径：

- **口径 A（产品默认）**：UFF 多取向初猜（seed 42 单口径）→ GFN2-xTB 优化
  → 结合能。即当前产品用户实际得到的结果。
- **口径 B（取向筛选）**：5 个随机取向（seed 42/101/202/303/404）各自做
  GFN2-xTB 优化、取复合物能量最低者；xTB 值即该取向结合能；Psi4 在该最优
  xTB 几何上做 CP 单点（`optimize=False`，几何经新增的 `complex_xyz` 参数注入）。

文献值是 S66 **平衡几何**上的 CCSD(T)/CBS；本基准几何来自 xTB 优化，几何来源
差异是系统偏差的一部分（水二聚体的全 Psi4 优化抽查用于隔离该因素）。

## 四、核心发现：瓶颈在几何初猜取向，不在电子结构方法

1. **取向命中时两档都准**。水二聚体（氢键基序容易被 UFF 初猜命中）两口径
   都达到误差 ≤0.12 kcal/mol；苯···水经取向筛选后 Psi4 误差 0.19。
2. **UFF 初猜对结合基序不敏感**。UFF 力场没有氢键方向性与 π-π 相互作用的
   物理，5 个取向在 UFF 层面能量接近，选出的"最低能取向"经常是错的基序：
   - 苯···水：口径 A 选到水远离苯环面的取向（−0.18），取向筛选后 xTB 找到
     OH-π 构型（−2.29），Psi4 在该几何上 −3.09（文献 −3.28）；
   - 甲酰胺二聚体：环形双氢键基序 5 个取向只部分命中（最好 −8.71 vs
     −16.12），取向间能量散布 2.45 kcal/mol；
   - 苯二聚体 / 苯酚二聚体：5 个取向全部收敛到相近的浅极小（取向间散布仅
     0.46 / 1.49 kcal/mol），xTB 优化无力从错误基序跳到 π-π 堆叠构型——
     这是**采样问题而非优化问题**，需要更好的初猜生成（如基于相互作用位点
     的几何模板）而非更多随机取向。
3. **方法间差异是二阶的**。xTB 与 Psi4 在同一几何上的结合能非常接近
   （5 体系最大差 1.3 kcal/mol），与文献值的偏差主要由几何决定。Psi4 档的
   增量价值在于：真 DFT 势能面（可继续优化到真平衡几何）、BSSE 校正、
   fchk 波函数输出供后续分析——而不是在错误几何上给出更准的单点。

## 五、结论与建议

- **Psi4 精度档达到设计目标**：几何合理时（水二聚体全优化口径）误差
  0.1 kcal/mol 量级，满足"论文定量数据复算"的定位；单点 CP 耗时
  8–48 s/体系，可接受。
- **xTB 快速档定位不变**：相对比较与趋势筛选。取向命中时绝对误差也可
  <1 kcal/mol，但不保证命中。
- **当前产品的首要改进不是换电子结构方法，而是复合物取向采样**：
  1. 短期：把口径 B 的「多取向 xTB 筛选」产品化（`embed_complex_xyz` 后接
     xTB 级筛选再定取向，每体系仅增秒级耗时；本次基准脚本即为原型）；
  2. 中期：对 π-π / 双氢键等已知基序加几何模板初猜（苯二聚体、苯酚二聚体
     这类散布小但全错的案例，随机取向救不回来）；
  3. Psi4 档建议默认 `optimize=True`（真 DFT 势能面优化能部分纠正初猜，
     水二聚体 17.4 s 可接受），单点 CP 作为快速选项。

## 六、口径与局限（引用时务必保留）

- 几何非 S66 平衡几何（除注明"全优化"的水二聚体外，均为 GFN2-xTB 优化几何）；
- 文献值为 CCSD(T)/CBS 含 CP 校正，本计算为 GFN2-xTB / ωB97X-D3BJ/def2-SVP+CP；
- 样本 5 个体系，MAE 不具统计代表性，仅作管线 sanity check；
- 甲酰胺二聚体即使在口径 B 下仍偏浅约 6–7 kcal/mol，属已知遗留（环形双氢键
  基序未被取向采样命中），非代码错误。
