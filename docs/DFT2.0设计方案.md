> 2026-08-25 起草。状态：**待用户审查**，确认后开工。
> 背景：用户指出 v1.0.0 的 DFT 模块算的是"两个单体之间的结合能"，科学对象不对——应是**两单体缩合形成的二聚体**与**其他物质**的结合能。同时希望引入画结构功能（类 ChemDraw），解决二聚体无 CAS 号、SMILES 难获取的问题。

## 一、科学对象修正：算什么

### 现状（v1.0.0）
E_bind = E(单体A) + E(单体B) − E(A·B 复合物) —— 预反应复合物的非共价结合，参考价值有限。

### 修正后（2.0）
先由两个单体**生成缩合二聚体**（醛+胺→亚胺键，复用现有 `render_imine_product` 的反应逻辑，输出真实二聚体 SMILES），再算二聚体与第三物质的结合能：

```
E_bind = E(二聚体·X 复合物) − E(二聚体) − E(X)
```

**X（第三物质）的可选类型**（前端做成选择器）：

| X 类型 | 科学意义 | 输入方式 |
|---|---|---|
| **另一个同样的二聚体**（默认） | π-π 堆积/自聚集倾向 → 结晶与成膜驱动力 | 自动复制，零输入 |
| **溶剂分子** | 二聚体在溶剂中的溶剂化/分散倾向 → 成膜环境筛选 | 常用溶剂下拉（甲苯/均三甲苯/二氧六环/DMF/水…）或自定义 SMILES |
| **另一个不同二聚体** | 异质堆积（供体-受体对） | 另一组单体自动生成 |
| **自定义分子** | 灵活探索（如基底模型物、调节剂） | 画板绘制 / SMILES 直输 |

### 计算管线变化
```
单体A + 单体B → [缩合反应] 二聚体 SMILES（自动，无需 CAS）
             → RDKit 3D + UFF 预优化 → xtb --opt（二聚体、X、复合物）
             → E_bind + gap + 偶极
```
- 多官能团单体先取**第一个缩合位点**的二聚体（与现有产物骨架口径一致）；二期可枚举多位点
- 二聚体 SMILES 展示在结果页，可一键复制、可收藏（收藏对象升级为"二聚体计算"）

## 二、结构画板（类 ChemDraw）调研结论

### 候选对比（GitHub 实测调研）

| 项目 | 星数 | 形态 | 许可 | 适配度 |
|---|---|---|---|---|
| **[epam/ketcher](https://github.com/epam/ketcher)** | **871★，2026-08-24 仍在更新** | TypeScript，官方 React 组件 `ketcher-react` | Apache-2.0 | ✅ 首选：专业化学画板（键/环/官能团模板），输出 SMILES/molfile，npm 直接装 |
| ggasoftware/ketcher | 59★ | 老版，已被 epam 版取代 | — | ❌ 过时 |
| openchemlib-js | ~200★ | 画板+计算混合 | BSD | 备选：更轻但化学编辑能力弱于 Ketcher |
| marvinjs | 商用 | 闭源付费 | ❌ | 排除 |

### 嵌入方案
- `npm i ketcher-react ketcher-core`（纯前端包，后端零改动）
- 在单体输入框旁加「画结构」按钮 → 弹出 Ketcher 模态画板 → 「确定」把 SMILES 回填输入框
- **DFT 页**：二聚体自动生成不用画；第三物质 X 的"自定义分子"用画板；也允许画出结构后**手动编辑自动生成的二聚体**（高级选项）
- **查询打分页**：同样可以加（单体输入方式变为：SMILES / CAS / 内置库 / **画结构**四种）
- 体积代价：ketcher-react 打包约 +1.5MB JS（懒加载，不用时不加载）

## 三、前端设计（DFT 页重构）

```
┌─ DFT 计算 ──────────────────────────────────────┐
│ 第一步：二聚体                                    │
│  [醛单体输入____] [画板] [CAS] [内置库] [历史]     │
│  [胺单体输入____] [画板] [CAS] [内置库] [历史]     │
│  → 自动生成预览：[二聚体结构图] 亚胺键缩合(位点1)   │
│                                                 │
│ 第二步：与什么计算结合能                           │
│  (●) 自身堆积（二聚体·二聚体）                    │
│  ( ) 溶剂分子 [下拉:甲苯▾]                        │
│  ( ) 另一组单体形成的二聚体 [展开两组输入]          │
│  ( ) 自定义分子 [SMILES___] [画板]                │
│                                                 │
│ 方法档位：(●) 精确 GFN2-xTB  ( ) 快速 GFN-FF      │
│           [开始计算]                              │
├─ 结果 ──────────────────────────────────────────┤
│  结合能 -x.xx kcal/mol │ 能隙 │ 偶极 │ [导出]     │
│  二聚体 SMILES [复制] [收藏] │ 结构图×3           │
│  ⚠️ 半经验方法仅供相对比较（常驻红线）              │
├─ 历史记录 ──────────────────────────────────────┤
└─────────────────────────────────────────────────┘
```

要点：
- 二聚体**自动生成+结构图预览**，用户在计算前确认化学结构正确（可选画板修正）
- "自身堆积"为默认——最贴合 COF 成膜结晶问题
- 查询打分页同步加「画结构」按钮（第四输入方式）

## 五、明确的风险

1. **二聚体生成化学正确性**：当前只取第一个缩合位点——对苯二甲醛+三胺类单体，真实产物可能多位点缩合/寡聚；界面要标注"示意单点缩合二聚体"，二期枚举
2. **二聚体+二聚体的体系原子数可能 80-120**，GFN2 优化耗时可能到 5-10 分钟——异步任务+进度提示必须做好，快速档（GFN-FF）作为日常推荐
3. **Ketcher 懒加载**：首屏不加压；画板在中英文混排下的 UI 文案以英文为主（Ketcher 无官方中文包，可接受）
