## 当日追加：画板白屏热修复 + v1.0.2 发布（479ffc9 / 5633fca + tag v1.0.2）

**用户反馈**：v1.0.1 点击「画结构」白屏。

**根因（双层，均 Electron 无头诊断实证）**
1. ketcher 渲染层含浏览器端条件式 `require("raphael")`（CJS 遗留写法），vite 产物中保留 → 浏览器无全局 require → KetcherPanel chunk 求值即抛 ReferenceError → React.lazy 拒绝且无错误边界 → 整树卸载白屏
2. 修复 1 后第二暴露层：Indigo WASM 初始化引用 Node 风格 `global`（未定义）→ 画板异步初始化失败、编辑器区域空白

**修复**
- 新增 `ketcher-require-shim.ts`（KetcherPanel 首个 import，ESM 求值序保证先于 ketcher）：注入 `window.require`（仅应答 raphael 返回真实模块）+ `window.global = window`
- StructureSketcher 加 `SketcherErrorBoundary`：画板任何加载/运行失败降级为对话框内中文提示，永不整页白屏
- 无头实证：修复前 ReferenceError + bodyLen 68k（白屏）；修复后零页面错误、bodyLen 165k、截图确认编辑器完整渲染（工具栏/元素表/环模板）

**发版**：v1.0.2 全流程（三处版本号 → vite → PyInstaller → 打包自检 → electron-builder → zip → Release 三资产），exe/zip 各 439MB。

**诊断工具沉淀**：`.tmp_xtb/diag4.js` Electron 无头点击诊断脚本（控制台+页面错误捕获+截图），以后前端交互 bug 都可先无头复现再修。

**发版纪律补充**：含前端新交互组件的发版，自证清单应加"无头点击关键按钮"一项——本次 v1.0.1 只验证了 chunk 可访问（200），没验证模块求值成功，漏网。
