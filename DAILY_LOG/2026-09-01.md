### 五项修复明细

1. **浅色模式侧边栏文字模糊**（问题1）
   - 根因：全局 `font-sans` 是「Times New Roman + 宋体」学术衬线栈，侧栏导航
     14px 宋体在 Windows 上走位图字形，叠加 `font-medium` 合成加粗与 /70 透明度
     → 发虚。
   - 修复：tailwind 新增 `fontFamily.ui`（Segoe UI + Microsoft YaHei UI），侧栏
     `aside` 换 `font-ui antialiased`；导航未激活态 /70→/90；`index.css` body
     全局加 `-webkit-font-smoothing: antialiased` 等三项抗锯齿。正文衬线风格不动。

2. **进度条提前显示 100%**（问题2）
   - 根因：`_stage_percent` 的「完成」关键词误中「Psi4 初始化完成 / 几何优化完成」
     等中途文案 → 100。
   - 修复：`_stage_percent` 阶段分级上限 90（100 仅由终态直接写入），并移除过于
     宽泛的「生成」关键词（曾把「正在生成缩合二聚体」错标 88）；前端三处展示
     钳制 `min(pct, 99)`（Dft 页进度条、全局悬浮片）。

3. **缺少「取消计算」按钮**（问题3）
   - 后端：`jobs.py` 新增 `_CANCEL_EVENTS` 注册表 + `request_cancel` +
     `cancel_event_for`；`engine._run_xtb` 由 `subprocess.run` 重构为 Popen +
     0.5s 轮询（取消/超时强杀并明确归类）；Psi4 `_run_psi4_script` 同样加取消
     轮询；新增 `JobCancelledError`；`compute_*` / `screen_complex_xtb` /
     `_xtb_guess` 全链路透传（仅非 None 时透传关键字，兼容旧测试伪造）。
     新终态 `cancelled`；`POST /api/dft/jobs/{id}/cancel`（终态→409，不存在→404）。
   - 前端：Dft 页进行中卡片加「取消计算」按钮 + 琥珀「计算已取消」提示条；
     全局悬浮片加停止图标；`DftTaskContext` 增加 `cancelTask` 与 cancelled 通知
     （toast.info）；恢复/轮询路径完整处理 cancelled。

4. **CREST 安装失败 → Docker 路线**（问题4）
   - 现状证据：conda `crest` 无 win-64、`crest4` 需 ete4（镜像缺失）、pip 无
     Windows wheel、GitHub 仅 Linux 资产 → Windows 本机装不了。
   - 落地：本机已装 Docker Desktop 4.88.1（winget）；`scripts/setup_crest_docker.ps1`
     （自提权 + WSL2 功能启用 + 现代 WSL 安装 + 内核更新 + 构建/验证 cof-crest
     镜像）；`scripts/docker/crest/Dockerfile`（miniforge3 + conda-forge crest/xtb，
     内置 XTBPATH）；应用侧 `conformers.py` 新增 docker 探测（60s 缓存）、
     `crest_mode()`（native/docker）、容器挂载运行回退、`conformer_engines` 报告
     mode 与引导文案。WSL2 需重启一次生效（CBS 已有 RebootPending 标记）。

5. **原子数错误显示 60**（问题5）
   - 根因：前端 `estTotalAtoms` 启发式（重原子×2×2 近似含氢）在苯甲醛+苯胺上
     错估为 60。
   - 修复：删除启发式；后端新增 `engine.atom_count_with_h`（RDKit AddHs 真实
     含氢口径）+ `GET /api/dft/atom-estimate`（pair= A+B；dimer=二聚体+X，
     self_stack 精确 2×二聚体；解析失败返回 null）；前端防抖 400ms 调取，
     Psi4 >50 原子警告改用真实数值并展示「二聚体 d + X x」拆解。
