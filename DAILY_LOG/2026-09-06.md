### pilot 真机踩坑修复（5 个，全部带回归测试）

1. DETACHED+NO_WINDOW 编排器拉起控制台子进程被 0xC000013A 秒杀 →
   finetune 子进程显式加同款 creationflags；
2. 反馈组合已在基础集（v6 含 TFPT+BD-CF3）时被去重丢弃 → 改为「已在
   基础集也加入 feedback_keys 加权」；反馈行 <5 条时全留训练切分；
3. 校准器单用早停验证集（负样本占优）把中等原始分单调压 0 → 分层校准
   样本；
4. guard/compare 子进程输出只按 UTF-8 解码 → Windows GBK 中文乱码解析
   失败 → 双编码回退；
5. **registry 激活版本被 DEFAULT_CHECKPOINT 覆盖**（版本名显示新版本、
   实际权重仍是 v5.4）→ 仅显式传入的 checkpoint 才算覆盖；
6. 闸门容差实测：同一 v5.4 两次运行 c_max 0.0479 ↔ 0.0615（树 3D 构象
   噪声 ±0.014）→ a_min/c_max 容差 0.03、聚合指标 0.01。
