### 三、本轮暴露并修掉的问题（含我自己的失误）

1. **测试污染真实数据（第二次同类事故）**：`resolver.INTAKE_PATH` 等 7 个导入期常量未被测试隔离，
   仓库 `data/literature/literature_intake.jsonl` 累积 335 行测试垃圾、dev 镜像库 paper 1/2 标题被覆盖。
   已在 conftest 覆盖全部常量 + 新增**隔离红线测试**（指向 `data/` 即失败）+ 清理并备份。
   随包库未受影响（`data/paper_templates`… 不打包 `data/literature/**`）。
2. **`pytest.ini` 带 BOM 导致全仓 pytest 起不来**（我用 PowerShell `Set-Content -Encoding UTF8` 写的，PS5.1 会加 BOM）。
   已去 BOM；同时记录反向教训：**PS5.1 的 .ps1 脚本反而需要 BOM**（否则中文被当 GBK 读、语法解析失败）。
3. **`tsc` 假绿**：`tsconfig.json` 是引用式空壳，此前多次"tsc 0 错"实为没检查。
   已加 `npm run typecheck`（= `tsc -b`），并纳入提交门禁。
4. **pair 模式收藏按钮被禁用**（用户实测阻塞）：它是创建"双分子特殊档案卡"的唯一入口。
   已解开（`4849db2`），并补齐 `buildDftSnapshot` 缺失的 `mode`/`job_id`/`conditions`，
   顺带修「刚收藏完追加按钮不出现 / 点到空 id」。
5. **Psi4 超时默认值错误**：90 原子体系 3600s 必然超时（实测需 65–70 分钟）→ 改为 >50 原子一律 3 小时；
   已用 `setx COF_DFT_TIMEOUT_PSI4=10800` 让**旧版本也能立刻生效**；被中断那次计算**抢救成功**
   （复用已收敛的 CP/单体能量 + 只补最后一步，交叉核对差 1.8e-6 Eh）。
6. **环境限制（本机新出现，值得记住）**：由本会话 shell 启动的**孙进程**在工作区外写文件会被拒 ——
   表现为 xTB 写不了 `%TEMP%\xtbrestart`、esbuild 删不掉 `%TEMP%\esbuild-*`、冻结后端建不了
   `E:\cof-build\...\data`。规避方式：把临时目录/数据目录放到仓库内（`pytest.ini --basetemp`、
   构建时 `TEMP=.tmp_xtb/vite-tmp`）。
